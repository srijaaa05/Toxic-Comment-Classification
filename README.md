Toxic-comment-classification

A Deep Learning-based Natural Language Processing project that automatically detects and classifies toxic comments from online platforms. The model is trained on the Jigsaw Toxic Comment Classification dataset and can identify multiple categories of toxicity, including:

* Toxic
* Severe Toxic
* Obscene
* Threat
* Insult
* Identity Hate

## Features

* Text preprocessing and cleaning
* Tokenization and sequence padding
* Deep Learning model using TensorFlow/Keras
* Multi-label classification
* Model evaluation and prediction
* Pre-trained model saved as `toxicity.h5`

## Tech Stack

* Python
* TensorFlow / Keras
* NumPy
* Pandas
* Scikit-learn
* NLP Techniques

## Dataset

The project uses the Jigsaw Toxic Comment Classification dataset containing user comments labeled across multiple toxicity categories.
